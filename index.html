Fusion: A Framework for Unified Sequential Token Adaptation in Vision Transformers

Aravind Pradeep, Samira Nazari, Mahdi Taheri, Christian Herglotz

48%
less inference energy, power-save setting
1.58 pp
accuracy recovered by staging the three in order
31.8%
fewer FLOPs for 0.09 pp of accuracy
ImageNet-1k · DeiT-S

Token merging, early exiting and token pruning each cut a Vision Transformer's inference cost alone, but combined they destabilise the intermediate representations. Fusion stages them so they cooperate (merge first, check confidence, prune only what continues), with routing modules that adapt compression per input and expose the accuracy/latency trade-off at inference time, no retraining.

01Merge

In the first half of the network, the most similar tokens are averaged together, a little at each of three steps.

02Exit early

At two checkpoints further in, an image stops as soon as the model is confident enough in its answer.

03Prune

In the last layers, tokens that barely matter are dropped from the images that continue.

The order is the point: running all three at once cost 1.62 pp of accuracy, and staging them recovers 1.58 pp. One trained model serves two settings, balanced and power-save, with no retraining.

Resume Tailor

Tailors a LaTeX résumé and cover letter to a job description, then refuses to compile any claim it cannot trace to the base CV.

3 gates before pdflatex · 106 tests · profile-driven, no personal data in code

Dogfooded on my own applications for machine learning engineering roles in Germany.

A tailoring LLM moves personal-project work under the employer's heading, invents numbers, and adds whatever the posting asks for. Three mechanical gates run on the rendered LaTeX: a regression gate for banned claims and attribution slips, a claim-backing gate that traces every number, skill and tool name to the base CV, and an omission gate that reports what tailoring dropped. Nothing compiles until every artifact is clean. Pairs with job-search-toolkit, which scans boards, filters roles and hands the cached JD straight to the tailor.
